# random-json-data-generator
# Обзор
Данный скрипт генерирует строку JSON, которая содержит элементы, наполненные случайными значениями фамилии, имени, пола, города, номера мобильного телефона, почты, года рождения.

# Для чего это может пригодиться?
Данный скрипт может быть полезен, например, в целях тестирования, когда требуется быстро и без весомых трудозатрат получить большое количество случайных данных.

# Требования
Python 3.12.7+

# Использование
1. Получите каким-либо образом директорию с данным скриптом.
2. Перейдите в данную директорию.
3. Выполните команду запуска скрипта:

   ```python random-json-data.py```

4. Команда без аргументов, как описано в п. 3 выведет на экран json длиной в один объект. Возможные аргументы, позволяющие управлять поведением скрипта:
  - ```--count=150```, где 150 - пример длины возвращаемого json. По умолчению значение аргумента равно 1. Пример: ```python random-json-data.py --count=150```.
  - ```--file=randomUsers.json```, где randomUsers.json - пример названия файла, в который необходимо записать результат. По умолчению значение скрипт пишет вывод в консоль. Если файла не существует, он будет создан. Пример: ```python random-json-data.py --file=randomUsers.json```.
Примечание: аргументы могут повторяться и указываться в любом порядке.
5. Получите результат: либо в консоли, либо в файле, в засимости от того, что было указано в аргументах.
